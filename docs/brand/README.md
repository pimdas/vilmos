Typografie: Recoleta SemiBold voor logo/koppen, Inter voor tekst/UI. Originele fontbestanden ontbreken. De website gebruikt lokaal beschikbare fallbacks; er zijn geen commerciële fonts gedownload.

Het gevouwen crème/oranje V-beeldmerk in public/website/brandmark.svg is een voorlopige vectorbenadering, geen origineel logobestand. Vervang dit bij beschikbaarheid door de originele SVG. De referentieafbeelding staat buiten de publiek geserveerde bestanden.
